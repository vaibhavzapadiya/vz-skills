# Distribution and Release Specification

Use the current official Claude Code distribution approach; do not assume the plugin format or commands from old examples.

## Required documentation

- supported Claude Code version/compatibility;
- prerequisites;
- local development/loading;
- installation;
- installation verification;
- updating;
- rollback;
- uninstall;
- troubleshooting;
- release/versioning;
- dependency and license inventory;
- contribution workflow;
- known limitations.

## Release safety

- avoid clobbering user settings or project instructions;
- inspect package contents before publishing;
- verify links and commands;
- document changes and breaking changes;
- preserve reproducible validation output;
- identify what was not tested;
- do not publish externally without appropriate authorization;
- do not claim production readiness if required acceptance criteria remain blocked.
