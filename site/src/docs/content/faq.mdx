### Does it replace Claude Code's permissions?

No. Claude Code's permissions and sandbox are the boundary. VZ hooks only ask or deny on top of them, and they fail open. See [Security and limits](/docs/security).

### Is it better than plain Claude Code?

Nobody knows yet. No comparison has been run, and none is claimed.

### Why `/vz-skills:plan` and not `/plan`?

Claude Code puts the plugin name in front of plugin commands. Use `npx vz-skills install --flat` for short names. See [Installation](/docs/installation).

### Why is it `/vz-status` and not `/status`?

So Claude Code's own `/status` keeps working.

### Does it run my scripts?

No. Discovery only reads files. With `--baseline` it runs one well-known test command, such as `npm test` or `pytest`.

### Will it read my `.env`?

No. VZ scripts never open `.env` files or keys, and the guards ask before anything else does.

### What happens to my uncommitted changes?

They are listed and left alone. If a change must touch them, Claude says so first.

### Why does it say UNKNOWN?

Because a guessed command is how an unrun test becomes a reported pass. Tell Claude the command, or add a script to your manifest.

### It is too much for a small fix.

Small, low-risk changes skip most steps. If the path looks like auth, payments or migrations, it is treated as high risk anyway. Use the `FAST` profile for lighter checks elsewhere.

### How do I change the profile?

Run `/setup FAST` (or `BALANCED`, `PRODUCTION`). For one shell, set `VZ_SKILLS_PROFILE`. See [Configuration](/docs/configuration).

### Can I turn the guards off?

Yes, on purpose. Lowering a guard needs an acknowledged override, and every session then prints a warning.

### What does it cost?

A small amount of context is added to each session. `claude plugin details` reports the exact figure. Each hook call takes 100 to 300 ms, and there are no network calls.
