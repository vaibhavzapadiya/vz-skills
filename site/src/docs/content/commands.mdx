<Lead>
24 skills in four groups. Every skill is a slash command.
</Lead>

These are the short forms from the flat install. With the plugin install, add `vz-skills:` in front, as in `/vz-skills:plan`. After a flat install `status` is `/vz-status`.

**Runs** says who can start a skill. *Auto* means Claude can also pick it when a request matches. *You* means only you can run it.
