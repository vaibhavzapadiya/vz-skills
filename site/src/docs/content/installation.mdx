<Lead>
Pick one install form. Do not use two in the same scope, or every skill shows up twice.
</Lead>

| You want | Run | Commands look like |
|---|---|---|
| Short commands (recommended) | `npx vz-skills install --flat` | `/plan`, `/discover` |
| The plugin as one unit | `npx vz-skills install` | `/vz-skills:plan` |
| Just a look | `npx vz-skills try` | `/vz-skills:plan`, one session only |

Claude Code puts the plugin name in front of plugin commands, and there is no setting to turn that off. The flat install avoids it by placing the skills in your own Claude config.

<Callout kind="note" title="Two renames">
With the flat install, `status` becomes `/vz-status` so Claude Code's own `/status` still works. `/review` replaces the built-in review command.
</Callout>

## Scope

Add `--scope` to choose where it goes.

| Scope | Where | Use it for |
|---|---|---|
| `user` (default) | Your Claude config | Every project on your machine |
| `project` | The repository's `.claude/` | Your team. Commit it. |
| `local` | The repository's `.claude/`, hooks in `settings.local.json` | Only you, in one repository |

## From a clone

```bash
claude --plugin-dir ./plugins/vz-skills                       # one session, nothing installed
claude plugin marketplace add /path/to/VZ-skills              # or install from the clone
claude plugin install vz-skills@vz-skills-marketplace
```

## Check, update, remove

```bash
npx vz-skills doctor                 # check Node, Claude Code, and the install
npx vz-skills@latest update          # add --flat for the flat form
npx vz-skills uninstall              # add --flat for the flat form, --purge to clean up fully
```

Your `.vz-skills/config.json` files are never removed.
