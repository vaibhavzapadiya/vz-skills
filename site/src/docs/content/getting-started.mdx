<Lead>
Install, check, and make your first change. Nothing in your project changes until you ask.
</Lead>

You need Claude Code 2.1.233 or newer and Node.js 18 or newer.

## Steps

<Steps>
<Step title="Install">

```bash
npx vz-skills install --flat
```

Restart Claude Code. Commands now look like `/plan` and `/discover`.

<Callout kind="note" title="Not on npm yet">
Until it is published, run `npm pack` in a clone, then `npx --yes ./vz-skills-0.1.0.tgz install --flat`.
</Callout>

</Step>
<Step title="Check">

```text
/vz-status
```

Shows your profile, hook status, and a short look at the repository. It changes nothing.

</Step>
<Step title="Pick a profile (optional)">

```text
/setup BALANCED
```

Creates `.vz-skills/config.json`. BALANCED is the default even without it.

</Step>
<Step title="Ask for a change">

```text
add rate limiting to the login endpoint
```

Claude picks the steps it needs, works in small slices, and ends with a report.

</Step>
</Steps>

## The report

```text
| # | Criterion                                  | Status       | Evidence                                     |
| 1 | /login returns 429 after 5 attempts/minute | VERIFIED     | pnpm test -- login.rate -> 3 passed (exit 0) |
| 2 | Metrics emitted for rejected attempts      | NOT VERIFIED | no test covers this; manual check not run    |

Verdict: done with limitations
```

Read the status column. `NOT VERIFIED` and `BLOCKED` are the things left for you.

## Long tasks

Save your place with `/checkpoint save`. Pick it up later with `/checkpoint resume`. When the work is done, `/pr` writes the pull request text from the same evidence.
