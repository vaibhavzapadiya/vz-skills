<Lead>
VZ Toolkit adds skills, agents and guardrails to Claude Code. It makes Claude look before it changes things, and say exactly what was checked when it is done.
</Lead>

```bash
npx vz-skills install --flat
```

## What you get

- **24 skills.** Slash commands such as `/discover`, `/plan` and `/verify`.
- **3 agents.** Read-only helpers that review code with fresh eyes.
- **3 hooks.** They ask before risky commands and file writes.
- **An installer and a config file.** One command installs it. One file sets how careful it is.

<Callout kind="note" title="A note on names">
The product is called VZ Toolkit. The plugin, the npm package and the commands use the name `vz-skills`, for example `npx vz-skills install` and `/vz-skills:plan`.
</Callout>

## The idea

- **Look first.** Claude reads your repository and says how sure it is about each fact.
- **Small steps.** Work is split into slices, and each slice has its own test.
- **Honest report.** At the end, every claim is marked as verified or not verified.

<Callout kind="note" title="What it is not">
It is not a security sandbox. Claude Code's own permissions stay in charge. See [Security and limits](/docs/security).
</Callout>
