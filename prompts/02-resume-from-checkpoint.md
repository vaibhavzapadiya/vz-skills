   - `docs/project/acceptance-matrix.md`

3. Compare the tracker with files and test results. Correct stale or unsupported status claims.
4. Identify the first incomplete task whose dependencies are satisfied.
5. Follow `prompts/01-phased-execution-protocol.md`.
6. Run relevant checks, fix failures, update evidence and trackers, then continue automatically.
7. Do not ask for phase-by-phase approval. Ask only for a real blocker, consequential choice, destructive action, credentials, or external side effect.
8. Never claim tests passed unless you ran them and observed the result.
9. Before ending, update the progress checkpoint with exact next steps, blockers, changed paths, and commands/results.

Continue until the definition of done is satisfied or a documented blocker prevents further progress.
