# Definition of Done

A requirement is done only when the criterion below is satisfied and evidence is recorded.

- [ ] Current official platform docs checked for the feature.
- [ ] Actual implementation exists; no placeholder masquerades as functionality.
- [ ] Scope and behavior are documented.
- [ ] Relevant tests or manual checks have been run.
- [ ] Results and limitations are recorded.
- [ ] Failure paths and missing dependencies are handled.
- [ ] Security and preservation implications reviewed.
- [ ] Diff reviewed for unrelated or destructive changes.
- [ ] Acceptance matrix updated.
- [ ] Requirements traceability updated.
- [ ] User-facing docs match behavior.

A release is done only after the final independent audit and an honest release decision.
